# ⚡ 电子工程计算器工具集

电子信息工程专业常用计算小工具合集，纯前端实现，无需安装任何环境，双击 `index.html` 即可在浏览器中使用，也支持手机访问。

## 功能

| 工具 | 说明 | 公式 |
| --- | --- | --- |
| 电阻色环解码器 | 支持 4 环 / 5 环电阻，点击色环颜色即可读出阻值与误差 | 阻值 = 数字 × 倍率 |
| RC 截止频率 | 输入电阻 R 与电容 C，计算低通/高通截止频率 | fc = 1 / (2πRC) |
| LC 谐振频率 | 输入电感 L 与电容 C，计算谐振频率 | f₀ = 1 / (2π√(LC)) |
| 欧姆定律 / 功率 | 输入 U、I、R 中任意两个量，自动计算第三个量与功率 | U = I·R，P = U·I |

所有计算器均支持常见单位自动换算（kΩ/MΩ、pF/nF/µF、µH/mH、mV/V/kV、mA/A 等），输入即实时计算。
